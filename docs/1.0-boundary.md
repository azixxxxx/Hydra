# Hydra 1.0 boundary and release gate

## Product boundary

Hydra 1.0 is a local macOS arm64 Codex plugin that delegates bounded engineering tasks to Claude Code through an existing Claude.ai Pro or Max login. It provides durable jobs, isolated write worktrees, controlled context, staged multi-model routing, manual allowance pacing, cancellation, recovery, and versioned MCP contracts.

Codex remains the only synthesizer and merge authority. Hydra does not commit, push, deploy, publish, apply a worktree patch, or make a product decision on the user's behalf.

## Included

- Nine MCP tools with strict input schemas and an explicit `response.ok` success/error discriminator.
- Sonnet, Opus, and Fable aliases plus validated full Claude family IDs.
- Subscription-only preflight, provider denylist, and no-model-fallback enforcement.
- Analyze, test, and execute modes with least privilege and preserved evidence.
- Durable queue, concurrency leases, session claims, process identities, cancellation, and crash reconciliation.
- Staged delegation groups with a one-lead default and hard context/session caps.
- Append-only manual allowance snapshots, exact-cohort empirical calibration, reservations, fixed-point weekly pacing, and safe final burn.
- MIT licensing, third-party notices, reproducible bundled `dist`, and public contribution/security guidance.

## Excluded

- Maintainer support or release gating for Linux, macOS x64, or Windows.
- npm or hosted marketplace publication.
- Automatic quota retrieval, browser automation, private account endpoints, or token-counting services.
- API billing, paid-overflow authorization, provider gateways, or automatic model fallback.
- Autonomous task scheduling, synthetic backlog generation, self-tuning routing, or learned model conversion ratios.
- Nested Claude teams, more than three fresh sessions, more than one Fable session, or more than two rounds.
- Automatic merge, commit, push, PR creation, deployment, or worktree cleanup.

## Release gate

The version can be labeled 1.0 only when all checks below have observed evidence:

1. Unit, integration, cross-process, transport, and built-bundle acceptance tests pass without invoking real Claude.
2. Lint and strict TypeScript checks pass.
3. Bundled server and worker build reproducibly and pass plugin validation.
4. Package, manifest, runtime envelope, license, README tool count, and supported-platform claims agree.
5. Invalid manifest/config state and retention failures keep all tools discoverable in degraded read-only mode; reads do not run reconciliation and every mutation, including cancellation, is blocked.
6. Final burn is unreachable below the 9,500-basis-point order-statistic coverage threshold and reachable with 19 clean exact-cohort observations when every other gate fits.
7. Delegation transport tests reject plan mismatch, duplicate indices, cap violations, second Fable activation, and premature conditional activation.
8. The maintained macOS arm64 live matrix verifies preflight, one job per supported model, continuation, cancellation tree, and isolation. Any live item not rerun for the release is labeled not rerun rather than inferred from mock coverage.
9. No credential-shaped fixture, state artifact, build output, or authored document is retained.

Linux evidence is welcome but is not a 1.0 release gate.

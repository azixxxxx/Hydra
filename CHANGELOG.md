# Changelog

All notable changes to Hydra are documented here.

## 1.0.0 - 2026-08-13

- Added nine versioned MCP tools with explicit input, output, and error envelopes.
- Added durable background jobs, bounded queues, cross-process locks, crash recovery, identity-safe cancellation, and resumable sessions.
- Added controlled Claude settings, subscription-only provider checks, no-model-fallback enforcement, scoped read access, and isolated write worktrees.
- Added staged delegation groups with single-lead defaults, strict panel caps, bounded context capsules, and usage aggregation.
- Added manually attested fixed-point allowance pacing, empirical forecasts, reservations, and a conservative final-burn policy.
- Declared macOS arm64 as the maintained platform; Linux remains community-owned and unverified.
